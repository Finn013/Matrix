## 🇷🇺 О приложении
Один HTML-файл без сервера. Данные хранятся на устройстве в зашифрованном виде и при желании синхронизируются с вашим GitHub-репозиторием.

### Возможности
- **Таблицы**: главный экран с разделами, список таблиц, строки и столбцы, форматирование, цвета, выравнивание, закрепление строк и столбцов, масштаб щипком или Ctrl+колесо.
- **Формулы**: около 80 функций на русском и английском (СУММ, СЧЁТЕСЛИ(МН), СУММЕСЛИ(МН), СРЗНАЧЕСЛИ(МН), ЕСЛИ, ВПР, ПОИСКПОЗ, ИНДЕКС, ПРОСМОТРX, даты, текст), каталог «📚 Все формулы» и конструктор с выбором ячеек галочками.
- **Дублирование и копии**: строки по ключу в другие таблицы с соответствием столбцов, копии ячеек и диапазонов в несколько таблиц, «живые» копии.
- **Шифрование**: пароль при первом запуске, AES-GCM, ключ через PBKDF2. Автоблокировка, смена пароля.
- **📁 Файлы**: зашифрованные вложения со статистикой по типам и объёму.
- **Синхронизация через GitHub** одной строкой `владелец/репозиторий;файл.json;токен` в ⚙️. Файл в репозитории зашифрован тем же паролем.
- Сохранение и открытие JSON, экспорт.

> Забытый пароль восстановить нельзя.

## 🇬🇧 About
A single HTML file, no server. Data is stored encrypted on the device and can sync with your GitHub repository.

### Features
- **Tables**: home screen with sections, table list, rows and columns, formatting, colors, alignment, frozen rows and columns, pinch or Ctrl+wheel zoom.
- **Formulas**: about 80 functions in Russian and English (SUM, COUNTIF(S), SUMIF(S), AVERAGEIF(S), IF, VLOOKUP, MATCH, INDEX, XLOOKUP, dates, text), an “📚 All formulas” catalog and a builder that picks cells with checkboxes.
- **Duplication and copies**: rows by key into other tables with column mapping, cell and range copies into several tables, live copies.
- **Encryption**: password on first launch, AES-GCM, key via PBKDF2. Auto-lock, password change.
- **📁 Files**: encrypted attachments with stats by type and size.
- **GitHub sync** with one line `owner/repo;file.json;token` in ⚙️. The file in the repository is encrypted with the same password.
- Save and open JSON, export.

> A forgotten password cannot be recovered.
