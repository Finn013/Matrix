Справка

Формулы — пиши в ячейке или в строке формул, начиная с «=». Буквы (A, B, C…) — это № колонки по порядку, не название. Аргументы разделяй точкой с запятой «;». Ссылка на другую таблицу: Январь!A1:A50 (если в названии есть пробелы — в кавычках: 'Мой отчёт'!A1). Кнопка «fx» — клик по ячейкам подставляет диапазон, кнопка «🧮 Формула» — собрать любую формулу: простые галочками по ячейкам, с условием и ЕСЛИ — в окне-конструкторе, кнопка «🔎 Формулы» — показать текст формул и подсветить, какие ячейки на что влияют.

Простые — считают по диапазону, без условий:

=СУММ(C2:C50) — сумма чисел в диапазоне. Текст и пустые ячейки пропускает.
=СРЗНАЧ(C2:C50) — среднее значение чисел (сумма делённая на количество).
=СЧЁТ(C2:C50) — сколько в диапазоне именно чисел. Пример: 5, 8, «нет», «», 3 → результат 3.
=СЧЁТЗ(C2:C50) — сколько вообще заполненных ячеек, включая текст. Тот же пример → результат 4.

С условием — условие в кавычках: точное значение «ПП», сравнение «>10» / «<>0» / ">=5", или маска «Ив*»:

=СЧЁТЕСЛИ(B2:B50;"ПП") — сколько ячеек в диапазоне равны «ПП».
=СЧЁТЕСЛИМН(B2:B50;"ПП";F2:F50;"✔️") — сколько строк подходит сразу под несколько условий (диапазоны сверяются построчно, можно добавлять ещё пары через «;»).
=СУММЕСЛИ(B2:B50;"ПП";D2:D50) — сумма из колонки D, но только там, где в колонке B стоит «ПП». Третий аргумент необязателен — если убрать, суммирует тот же диапазон, где ищет условие: =СУММЕСЛИ(C2:C50;">10").
=СРЗНАЧЕСЛИ(B2:B50;"ПП";D2:D50) — среднее из колонки D там, где в B стоит «ПП». =СРЗНАЧЕСЛИМН(D2:D50;B2:B50;"ПП";F2:F50;"✔️") — с несколькими условиями (диапазон для среднего первым).
=СУММЕСЛИМН(D2:D50;B2:B50;"ПП";F2:F50;"✔️") — то же самое, но сразу с несколькими условиями. Важно: здесь диапазон для суммы идёт первым аргументом, а у СУММЕСЛИ — третьим. Порядок разный, легко перепутать.

Все остальные формулы (МИН, МАКС, ОКРУГЛ, ВПР, ИНДЕКС, ПОИСКПОЗ, СЦЕП, ЛЕВСИМВ, СЕГОДНЯ, РАЗНДАТ, ЧИСТРАБДНИ и др.) — «🧮 Формула» → «📚 Все формулы»: там поиск, описание и окно, где каждое поле подписано. Операторы: + - * / ^ (степень), & (склеить текст: =A2&" "&B2). Даты — текстом ДД.ММ.ГГГГ.

Логика:

=ЕСЛИ(B2="ПП";1;0) — если условие верно, ставит первое значение, если нет — второе. Можно текст: =ЕСЛИ(B2="ПП";"да";"нет"), можно сравнение: =ЕСЛИ(C2>100;"много";"мало").

Если формула показывает ошибку:

#ОШИБКА! — опечатка в формуле или неверные аргументы.
#ИМЯ? — такой формулы не существует, проверь название.
#ССЫЛКА! — ссылка ведёт на несуществующую ячейку или таблицу.
#ЦИКЛ! — формула ссылается сама на себя, напрямую или через цепочку других ячеек.

Шпаргалка — что для чего:

сложить числа — СУММ · среднее — СРЗНАЧ · сколько чисел — СЧЁТ · сколько заполнено (с текстом) — СЧЁТЗ · сколько подходит под одно условие — СЧЁТЕСЛИ · под несколько условий — СЧЁТЕСЛИМН · сумма по одному условию — СУММЕСЛИ · сумма по нескольким условиям — СУММЕСЛИМН · среднее по условию — СРЗНАЧЕСЛИ / СРЗНАЧЕСЛИМН · одно из двух значений по условию — ЕСЛИ

Выпадающий список для ячеек — меню колонки (⋮) → «Тип ячеек / список значений…» → перечисли варианты (например ✔️ и х), каждый с новой строки. После этого клик по ячейке открывает выбор вместо ручного ввода.

Форматирование ячейки — выдели ячейку, вверху появится панель: жирный/курсив/подчёркнутый, выравнивание по горизонтали и вертикали, цвет текста.

Связка (правое окно с данными) — см. подсказку прямо в окне «🔗 Связка». Коротко: одна таблица со списком (например «Работники»), несколько таблиц-источников с теми же именами (например по месяцам) — клик по имени показывает все его данные сразу.

Кнопки главного экрана — ⚙️ Настройки → «Кнопки главного экрана»: каждая кнопка открывает выбранную таблицу одним нажатием.

Заметка «📝» — быстрые записи для себя, поддерживает простой Markdown (**жирный**, *курсив*, # заголовок, - список). Можно потянуть за нижний правый уголок, чтобы увеличить окно.

Сохранение — всё сохраняется на устройстве автоматически и в зашифрованном виде. 💾 JSON — незашифрованная копия в файл, 📂 Открыть — загрузка из него. ☁️ Синк — отправка и загрузка через приватный GitHub-репозиторий, шифруется тем же паролем.

Пароль — придумывается при первом запуске и шифрует все данные (на устройстве и в GitHub). В файле его нет, восстановить забытый пароль нельзя. Сменить — ⚙️ Настройки, 🔒 — заблокировать сразу.

📁 Файлы — шифруются на устройстве и хранятся в вашем GitHub-репозитории; вверху статистика: число файлов, объём, разбивка по типам.

Дублирование

Ячейки берутся по порядку: слева направо, сверху вниз, в том порядке, как перечислены. Копируются значения (результаты формул тоже), в одну сторону: правки в живой копии перезапишутся источником.
